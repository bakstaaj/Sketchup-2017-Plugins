# STL Manifold Check for SketchUp 2017

Checks selected edges, faces, groups, or component instances for open boundaries, loose edges, and edges shared by more than two faces. Problem edges are highlighted in red.

## Install

Download [STL_Manifold_Check_0.1.6.rbz](https://github.com/bakstaaj/Sketchup-2017-Plugins/releases/download/stl-manifold-check-v0.1.6/STL_Manifold_Check_0.1.6.rbz). In SketchUp 2017 choose **Window > Extension Manager > Install Extension** and select the RBZ. Restart SketchUp if prompted.

The extension checks only the current selection when there is a selection; with an empty selection it checks the model. Press **Esc** to clear the edge highlight.
